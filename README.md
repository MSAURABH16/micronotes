# MicroNotes
A simple note-taking app built with React and Node.js.
Created Apis for adding and retrieving notes. The frontend is built with React, and the backend is built with Node.js and Express.

API Endpoints:
- GET /api/notes: Retrieve all notes.
- POST /api/notes: Add a new note. The request body should contain the title and content of the note.


how to run the project:
1. Clone the repository.
2. Navigate to the project directory.
3. Install dependencies for both the client and server:
   - For the client: `cd client && npm install`
   - For the server: `cd server && npm install` 
4. Start the server:
   - `cd server && npm start`
5. Start the client:
   - `cd client && npm run dev`
